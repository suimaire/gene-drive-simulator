# 유전자 드라이브는 어떻게 퍼질까?

고등학교 생명과학 수업 마무리(약 4분)용 가상 개체군 시뮬레이터.
멘델 유전(e = 0)과 호밍 드라이브(e 조절) 두 집단을 나란히 놓고,
D/W 부모의 D 전달 확률 (1 + e) / 2 가 세대가 지나며 자손 구성비를 어떻게 바꾸는지 보여 준다.

공개 주소: <https://suimaire.github.io/gene-drive-simulator/>

## 로컬 실행, 테스트와 빌드

Node.js 24와 npm을 사용한다.

```
npm ci
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 계산 검증 (Vitest)
npm run build      # dist/index.html 한 파일로 빌드
```

`dist/index.html`은 스크립트와 스타일이 모두 들어 있는 단일 파일이라 Edge에서 더블클릭으로 열어도 오프라인으로 실행된다.

## 조작

- 가상 방사: 두 집단(W/W 72마리)에 D/W 수컷 8마리를 한 번 도입
- 한 세대 관찰: 교배와 유전, 자손 등장 단계에서 멈춤. 다시 누르면 다음 단계
- 재생/일시정지(스페이스), 1배/2배 속도, 처음으로
- 모기를 누르면 그 개체의 부모와 물려받은 대립유전자를 확대해 보여 줌
- 하단 LMO 질문, 모형과 출처(가정, 세대별 기록, 참고문헌)
- 난수 시드: 주소 끝에 `?seed=숫자` (기본 52)

## 구조

- `src/model/` 유전 계산(genetics), 두 집단 실험(experiment), 세대 전환 타임라인(director). 화면과 분리된 순수 TypeScript
- `src/view/` Canvas 모기 렌더러(habitat, mosquito), SVG 그래프(chart)
- `tests/` 계산 및 타임라인 검증

## 모형의 적용 범위

이 수업 모형은 크기가 고정된 가상 집단에서 대립유전자 전달 확률이 자손 구성에 미치는 영향을 비교한다. D 보유 개체 비율은 D/W 또는 D/D인 개체의 비율이며, D 대립유전자 빈도는 모든 대립유전자 중 D의 비율이다. 집단의 공간 이동, 유전자형에 따른 적합도 차이와 저항성은 모형에서 제외한다. 실제 환경 방출 후 확산이나 생태적 영향을 예측하는 데는 별도의 자료가 필요하다.

## 배포

`main`에 푸시하면 GitHub Actions가 계산 테스트와 TypeScript 검사를 실행하고, 빌드한 `dist/`를 GitHub Pages에 배포한다.
